# FrontierSeminar

This is the repository for the RPI Math Frontier Seminar. The seminar website can be found [here][https://quantummanybody.github.io/FrontierSeminar/].

`index.html` is the primary file for the website. It also is read by the `flyer_maker` template. See the README in the `flyer_maker` folder for instructions on generating fliers.
